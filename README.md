# ResearchMind — Multi-Agent AI Research Assistant

ResearchMind is a Python-based AI research assistant that automates the process of researching a topic, gathering information from the web, extracting relevant webpage content, and generating a structured research report. It uses multiple AI agents and chains to divide the research workflow into smaller, manageable steps.

## 🚀 Features

- **Automated Web Search:** Uses Firecrawl to find relevant web resources based on a user-provided research topic.
- **Intelligent Content Extraction:** Uses Requests and Beautiful Soup to extract readable text from selected webpages.
- **AI-Powered Report Generation:** Uses Google Gemini and LangChain to generate structured research reports.
- **Report Evaluation:** Includes a critic chain that reviews the generated report and provides feedback.
- **Multi-Agent Workflow:** Separates web search, content reading, report writing, and report evaluation into distinct stages.
- **Topic-Based Research:** Allows users to enter a research topic and initiate the entire workflow from the terminal.

## ⚙️ How It Works

ResearchMind follows a four-step research pipeline:

1. **Search Agent:** Receives the research topic and uses Firecrawl to discover relevant web resources.
2. **Reader Agent:** Selects a relevant URL and extracts webpage content for deeper research.
3. **Writer Chain:** Combines the search results and extracted content to generate a structured report.
4. **Critic Chain:** Evaluates the generated report and returns feedback on its quality.

```text
        User Research Topic
                 |
                 v
          Search Agent
                 |
                 v
          Firecrawl Search
                 |
                 v
          Reader Agent
                 |
                 v
       Webpage Text Extraction
        (Requests + Beautiful Soup)
                 |
                 v
            Writer Chain
                 |
                 v
          Research Report
                 |
                 v
            Critic Chain
                 |
                 v
        Report + Critic Feedback
```

## 📋 Prerequisites

Before running ResearchMind, ensure you have:

- Python installed
- A Google Gemini API key
- A Firecrawl API key
- Git (optional, for cloning the repository)

## 🔧 Installation and Setup

### 1. Clone the repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd ResearchMind
```

### 2. Create a virtual environment

```powershell
python -m venv venv
```

### 3. Activate the virtual environment

```powershell
.\venv\Scripts\Activate.ps1
```

If PowerShell blocks activation, you can use the virtual environment's Python executable directly:

```powershell
.\venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 4. Install dependencies

```powershell
python -m pip install -r requirements.txt
```

### 5. Configure environment variables

Create a `.env` file in the project root and add your API keys:

```env
GOOGLE_API_KEY=your_google_gemini_api_key
FIRECRAWL_API_KEY=your_firecrawl_api_key
```

Replace the placeholder values with your actual API keys. Never upload your `.env` file or expose your API keys publicly.

### 6. Run the application

```powershell
python main.py
```

Enter a research topic when prompted, for example:

```text
Enter a research topic: Quantum theory
```

ResearchMind will then execute the research pipeline and display the search results, extracted content, generated report, and critic feedback in the terminal.

## 📄 Report Structure

The report generated by the writer chain is designed to contain:

- **Introduction:** An overview of the research topic.
- **Key Findings:** Important information gathered during the research process.
- **Conclusion:** A summary of the main insights.
- **Sources:** References or URLs associated with the research.

The critic chain separately reviews the generated report and provides feedback.

## ⚠️ Limitations

- Search results depend on the availability and relevance of external web resources.
- Some websites may block automated requests or return incomplete content.
- Gemini API requests may occasionally fail because of temporary service unavailability, rate limits, or quota restrictions.
- Generated reports may contain inaccurate or incomplete information and should be verified against the original sources.
- The quality of the final report depends on the search results and the content successfully extracted from webpages.
